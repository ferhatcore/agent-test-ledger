# Referencing records in Project OS

A task or QA note in [Project OS](https://github.com/ferhatcore/claude-codex-project-os) can link to a ledger record. Keep its existing task format and add the record path alongside the acceptance criterion.

```md
Acceptance criterion: greeting trims surrounding spaces.
Test record: repos/catalog/.test-ledger/<actual-UUID>.json
Test command: node path/to/agent-test-ledger/ledger.mjs run --task "T-42" --agent codex --client cli --artifact cli.mjs --artifact cli.test.mjs -- node --test --test-reporter=tap cli.test.mjs
```

In the QA note, record the verification result:

```md
Record reviewed: repos/catalog/.test-ledger/<actual-UUID>.json
Verification root: the repository that contains the tracked files
Integrity: consistent / invalid
Tests: the recorded test status
Related files: current / stale / untracked
QA decision: acceptance criterion checked against current evidence
```

Use the UUID generated by the actual run. A valid hash does not replace review or Git approval. These examples show file references; a native Project OS integration has not been tested.
