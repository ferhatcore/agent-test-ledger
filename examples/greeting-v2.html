Limits of this record

  • Labels are user supplied. They do not prove a Claude or Codex session ran.
  • A hash checks consistency. A signature checks possession of the supplied key. Neither proves honest execution.
  • Only explicitly listed files are checked. Before/after snapshots cannot detect changes that were reverted during the run.
  • Test counts describe recognized Node TAP output or a Jest/Vitest JSON or pytest JUnit report; a malicious command can forge these.
  • Raw output is not stored. No secret removal guarantee is provided for task names, arguments or paths.
  • The command ran with the user's permissions. Managed cleanup covers its Linux process group or Windows job; direct scope covers only the immediate child. Other sessions, brokers and external services can escape these boundaries. This tool is not a sandbox.
  • Opening this static report does not refresh file hashes. Regenerate it to check again.
