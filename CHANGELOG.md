# Changelog

## 0.10.0 (unreleased)

- Parse pytest's built-in JUnit XML reports with bounded, strict UTF-8/XML validation.
- Record unauthenticated environment and hook observations separately from caller labels.
- Emit schema-2 records while preserving schema-1 verification and signatures.
- Manage ordinary descendants with Linux process groups or Windows creation-time Job Objects.
- Record cleanup outcomes independently and require confirmed selected-scope cleanup for current passing evidence.
- Provide explicit direct-child scope and bounded interruption, helper-failure and output handling.
- Check real runners and offline package installation on Windows/Linux with Node 22 and 24.

## 0.9.1

- Record commands, process outcomes, test counts and file freshness in separate fields.
- Parse Node TAP and JSON reports from direct Jest/Vitest invocations.
- Reject empty test files as current passing evidence.
- Bound command output and execution time, and check artifact paths against the project root.
- Support optional Ed25519 signatures and escaped, offline HTML reports.
- Include CLI guides, examples and regression tests.
- Update installation documentation and package metadata.
